terget is installed

Commands include your login cookies for the link's site, so downloads behind a login work in the terminal. Allow access once here, or skip and terget will ask the first time you copy a link from each site. Cookies are read only when you use the menu, and never leave your computer.

Usage

Right-click a link → Copy download command → curl, wget or axel. The command goes to the clipboard and the toolbar button shows ✓, or ! with the reason on hover.

Shell
Shell history

Works with bash HISTCONTROL=ignorespace and zsh setopt HIST_IGNORE_SPACE; commands contain session cookies.

Extra arguments

Inserted unquoted before the URL, e.g. -n 8 for axel or -C - for curl.

Cookie access

terget asks the first time you copy a link from a site, and reads that site's cookies only when you click the menu.
