# Changelog

## 0.2.3

- The menu now appears only on links terget can copy (web links, and links
  that contain the file itself), no longer on email and other links.

## 0.2.2

- Links that contain the file itself (such as license keys generated by a
  page) now work: the copied command saves that content to a file
  (`download.txt`, or another extension depending on the content). Before, the
  menu didn't appear on these links.
- The menu now appears on every link. If a link has nothing to download, the
  toolbar button shows **!** and the reason when you hover over it.

## 0.2.1

First public release.

- Right-click any link and choose **Copy download command** → **curl**,
  **wget** or **axel**. The command downloads the file with your browser's
  cookies, so files behind a login download the same way in a terminal.
- The browser never opens the link, so single-use download links stay valid
  for the command.
- Choose your shell (bash, zsh, sh, fish or PowerShell 7.3+) and keep copied
  commands out of your shell history.
- Cookie access is up to you: allow all sites once after installing, or one
  site at a time when you first use it.
